# Star's Sweet Treats — Website Demo (Option 1: static site + Jotform)

One-page static site for Star's Sweet Treats, built to the settled layout:
green hero with her cream script logo, treats & prices from her confirmed
price list, how ordering works, the live Jotform order form embedded on the
page, short verified-only About, green footer.

- All photos are Star's own (from her Facebook/Instagram). No stock images.
- All wording traces to her paper order form or her own posts.
- The order form is the production Jotform (ID 263046130087047) embedded —
  submissions from this demo are REAL submissions to that form.
- Hosted with GitHub Pages. Demo only — not linked publicly yet.
